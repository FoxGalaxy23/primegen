# ttf_render — растеризация шрифтов

Собственный растеризатор TrueType/OpenType с антиалиасингом (накопление площади), кернингом (GPOS/kern), кэшем начертаний по размерам.

## Форматы шрифтов
| Формат | Реализация |
|---|---|
| TTF / OTF с TrueType-контурами (`glyf`) | `start.c` |
| **OTF с PostScript-контурами (`CFF `)** | `cff.c` — разбор CFF (в т.ч. CID-шрифты: FDArray/FDSelect, локальные/глобальные подпрограммы) и интерпретатор charstring'ов Type 2 (hint-операторы, flex, арифметика). Кубические кривые приводятся к квадратичным (`cc_curve` в `start.c`) с допуском 0,25 единицы шрифта; направление контуров приводится к TrueType (нужно синтетическому bold). Не поддерживается CFF2 (вариативные) |
| **WOFF** | zlib |
| **WOFF2** | `woff2.c` — разбор каталога (UIntBase128, 255UInt16), распаковка единым потоком **Brotli** (`brotli.c`), обратное преобразование таблиц `glyf`/`loca` (потоки nContour/nPoints/flags/glyph/composite/bbox/instruction, triplet-кодирование, bitmap перекрытий) и `hmtx` (восстановление lsb), сборка sfnt с контрольными суммами. Коллекции (ttc) не поддерживаются |

`brotli.c` — декодер Brotli (RFC 7932) с нуля: коды Хаффмана, контекстные карты, блочные переключения, кольцо дистанций, словарь и 121 преобразование слов.
Словарь и таблицы встроены в `brotli_tables.inc` (генерация: `tools/gen_brotli_tables.py` из эталонной реализации Brotli, MIT — см. `THIRD_PARTY.md`).

## Выбор начертания
`font_manager` хранит все `@font-face` семейства (вес, курсив); раскладка и отрисовка выбирают начертание по `(семейство, насыщенность, курсив)`
(`font_manager_get_styled`). Синтетические bold/italic включаются, только если настоящего начертания в семействе нет. Так работают наборы вроде
Font Awesome (regular 400 / solid 900 / brands) и семейства с несколькими весами (Source Sans и т. п.).
Имена семейств проходят CSS-раскрытие экранирования (`Font\ Awesome\ 7` → `Font Awesome 7`).

### Шрифт из нескольких частей (unicode-range)
Несколько `@font-face` с одним `(семейство, вес, курсив)` и разными файлами — это части одного шрифта (так Google Fonts отдаёт `latin`, `cyrillic`, …).
`font_manager` не заменяет их друг другом, а связывает цепочкой fallback в порядке регистрации (`link_group`): глиф берётся из первой части, где он есть,
затем из дефолтного шрифта. Пример: `tests/pages/unicode_range/t.html`.

## Проверка
`python3 tests/fonts/check.py` (нужны `pip install brotli fonttools`): Brotli на 108 потоках (качества 1/5/11, окна, режимы), WOFF2→TTF на системных шрифтах
(глифы, bbox, инструкции, метрики и все остальные таблицы против независимой распаковки fontTools), контуры CFF против fontTools.
Дополнительно разработка велась с фаззингом под ASAN/UBSan: Brotli — 12400 испорченных потоков, WOFF2 — 660 испорченных контейнеров.
Утилиты: `tools/brotli_cli.c`, `tools/woff2_cli.c`, `tools/cff_dump.c`.
